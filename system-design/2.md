# 5. The Most Important Component: Autoscaler

This is the “brain of scaling”.

```go id="auto1"
func AutoScale(service ServiceSpec, metrics float64, current int) int {
    target := service.TargetCPU

    if metrics > target {
        // scale up
        if current < service.MaxReplicas {
            return current + 1
        }
    }

    if metrics < target*0.5 {
        // scale down
        if current > service.MinReplicas {
            return current - 1
        }
    }

    return current
}
```

# 7. Scheduler (places containers on nodes)

When scaling up:

```go id="sch1"
func PickNode(nodes []Node) Node {
    // simplest: least CPU usage
    best := nodes[0]

    for _, n := range nodes {
        if n.CPUUse < best.CPUUse {
            best = n
        }
    }
    return best
}
```

# 9. Control Loop (this is Kubernetes-like behavior)

This loop runs forever:

```go id="loop1"
for {
    metrics := GetClusterMetrics()

    for _, service := range services {
        current := GetReplicaCount(service.ID)

        newCount := AutoScale(service, metrics[service.ID], current)

        if newCount > current {
            scaleUp(service, newCount-current)
        }

        if newCount < current {
            scaleDown(service, current-newCount)
        }
    }

    time.Sleep(2 * time.Second)
}
```

THIS is your Kubernetes-style behavior.
